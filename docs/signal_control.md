# 시연용 능동 신호 제어

## 제어 기준

Raspberry Pi Relay가 1초마다 받는 `vehicle_count` 최근 5개를 메모리에 보관하고 평균을 계산한다. DB 조회는 제어 경로에 사용하지 않는다.

| 최근 5초 평균 | 상태 | 다음 초록불 |
| ---: | --- | ---: |
| 0~6 | 한산 | 5초 |
| 6 초과~11 | 보통 | 10초 |
| 11 초과 | 혼잡 | 15초 |

신호 순서는 `초록 → 노랑 2초 → 빨강 5초 → 초록`이다. 초록불이 시작될 때 가장 최근 5개 평균으로 해당 초록불 길이를 결정하며, 진행 중인 신호를 중간에 단축하지 않는다.

## Bluetooth와 안전 동작

- Pi 장치: `/dev/rfcomm0` (환경변수 `SIGNAL_DEVICE`로 변경 가능)
- UART: 9600 baud, 8N1
- Pi는 현재 색을 1초마다 `SET,1,RED|YELLOW|GREEN` 형식으로 보낸다.
- 유효한 `vehicle_count`가 5개 쌓이기 전에는 빨강을 유지한다.
- 데이터가 3초 넘게 끊기면 평균 버퍼를 비우고 빨강으로 복귀한다.
- STM32도 유효 명령을 5초간 받지 못하면 자체적으로 빨강으로 복귀한다.

이 기준은 짧은 시간 안에 동작을 보여주기 위한 시연 모드다. 실제 신호 제어 시간과 안전 규정으로 해석하지 않는다.

# System Architecture

## 1. 시스템 개요

본 프로젝트는 **센서 데이터와 객체 탐지 데이터를 수집하고, 이를 Raspberry Pi 4 기반 중계 서버에서 1차 저장한 뒤 Ubuntu VM 서버의 MariaDB에 최종 저장하여 시각화 및 분석하는 구조**로 구성한다.

“C 기반의 경량 데이터 수집·중계 서버를 설계하고, 제한된 임베디드 자원 안에서 안정성과 효율을 높이는 것”

수집된 데이터는 단순 저장에 그치지 않고, 시간대별·센서별·조건별로 조회하고 비교하여 데이터가 가지는 의미와 패턴을 확인하는 것을 목표로 한다.

---

## 2. 전체 시스템 구성도

```text
[객체 탐지 데이터]        [센서 데이터]
        │                     │
        └─────── Wi-Fi ───────┘
                  │
                  ▼
        [Raspberry Pi 4 Server]
        - 데이터 1차 수신
        - SQLite 임시 저장
        - 중계 서버 역할
                  │
                  ▼
            네트워크 전송
                  │
                  ▼
      [Ubuntu VM Server + MariaDB]
        - 데이터 최종 저장
        - 중앙 데이터 관리
                  │
                  ▼
          [데이터 조회 / 가공]
                  │
                  ▼
           [데이터 시각화]
                  │
                  ▼
      [PC 화면에서 데이터 분석]
```

## 3. 각 구성 요소 역할

### 객체 탐지 데이터 생성 장치

도로 영상에서 생성된 객체 탐지 결과 데이터를 Wi-Fi를 통해 Raspberry Pi 4 서버로 전송한다.

객체 탐지 기능의 세부 구현 방식과 데이터 형식은 담당자의 구현 결과에 따라 추후 확정한다.

---

### 센서 데이터 수집 장치

조도, 온도, 습도, 소음 등 환경 센서에서 측정한 데이터를 수집하고 Wi-Fi를 통해 Raspberry Pi 4 서버로 전송한다.

---

### Raspberry Pi 4 Server

Raspberry Pi 4는 센서 데이터와 객체 탐지 데이터를 먼저 수신하는 **중계 서버** 역할을 담당한다.

주요 역할은 다음과 같다.

* 센서 데이터 수신
* 객체 탐지 데이터 수신
* SQLite에 데이터 1차 저장
* 네트워크 장애 시 데이터 임시 보관
* Ubuntu VM 서버로 데이터 전달

SQLite는 최종 저장소가 아니라 **네트워크 장애 시 데이터 유실을 방지하기 위한 로컬 버퍼 및 임시 저장소**로 사용한다.

---

### Ubuntu VM Server + MariaDB

Ubuntu 가상머신에 MariaDB를 구축하여 Raspberry Pi 4에서 전달받은 데이터를 최종 저장한다.

주요 역할은 다음과 같다.

* Raspberry Pi 4에서 전달된 데이터 수신
* MariaDB에 데이터 저장
* 데이터 조회 및 관리
* 데이터 시각화를 위한 데이터 제공

---

### 데이터 시각화

MariaDB에 저장된 데이터를 시각화 도구를 통해 사용자가 확인하기 쉬운 형태로 표현한다.

단순히 데이터를 표시하는 것이 아니라 다양한 기준으로 데이터를 조회하고 비교한다.

예시:

* 시간대별 차량 수 비교
* 시간대별 센서값 변화
* 소음이 높은 순서대로 데이터 정렬
* 온도 / 습도 / 조도 변화 비교
* 특정 시간대의 센서 데이터와 객체 탐지 데이터 비교

이를 통해 수집된 데이터의 변화와 관계를 확인하고 **데이터가 가지는 의미와 패턴을 분석**한다.

---

## 4. 전체 데이터 흐름

```text
데이터 생성
   │
   ├─ 객체 탐지 데이터
   │
   └─ 센서 데이터
           │
           ▼
      Wi-Fi 통신
           │
           ▼
   Raspberry Pi 4 Server
           │
           ▼
      SQLite 1차 저장
           │
           ▼
      Ubuntu VM Server
           │
           ▼
        MariaDB
           │
           ▼
     데이터 조회 / 가공
           │
           ▼
       데이터 시각화
           │
           ▼
   데이터 의미 및 패턴 분석
```
